# 캐릭터 PNG 차용

이 폴더의 픽셀 아트 캐릭터 이미지는 **W17ant/Claude-Office** 프로젝트에서 차용했습니다.

- 출처: <https://github.com/W17ant/Claude-Office>
- 라이선스: **MIT**
- 원본 위치: `docs/images/<캐릭터>.png`
- 원본 크기: 197×527px (다운스케일하여 사용: 약 50×134px)

## 매핑

| 우리 방 | 차용 파일 (원본 캐릭터) |
| --- | --- |
| `tistory` (티스토리 발행실) | michael-scott.png → tistory-a.png / pam-beesly.png → tistory-b.png |
| `errors` (에러 감시실) | dwight-schrute.png → errors-a.png / angela-martin.png → errors-b.png |
| `graph` (지식 그래프실) | jim-halpert.png → graph-a.png |
| `improve` (자기 개선실) | kelly-kapoor.png → improve-a.png |
| `notebook` (노트북LM실) | creed-bratton.png → notebook-a.png |
| `infra` (인프라/동기화실) | stanley-hudson.png → infra-a.png |
| `trend`, `blog` | 캐릭터 sprite 미배정 (방 박스 + decoration만) |

소스코드 내 `src/scene/drawCharacter.ts` 상단 주석과 본 CREDITS.md에 동일하게 명시.
